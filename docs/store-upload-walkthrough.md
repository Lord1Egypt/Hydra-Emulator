# Microsoft Store submission

1. Open the Hydra Emulator product in Partner Center and copy its package identity and publisher.
2. Build the [MSIX package](store-msix.md) using those values. Open the generated manifest and confirm they match the reserved product.
3. Create a submission in Partner Center. Upload the package and enter your pricing, markets, age rating, and support details.
4. Fill out the English listing using [the suggested copy](store-listing.md). Supply screenshots from the current Hydra build and the published [privacy policy](privacy.md).
5. Review the submission and certification notes before sending it for certification.

A Store submission uses its own publishing process. The source repository and GitHub release assets can be maintained independently.
