# Microsoft Store listing

## Short description

Run Android apps on Windows. Install APKs and open apps from Windows shortcuts.

## Description

Hydra Emulator brings Android apps to your Windows desktop. Drop an APK into Hydra, then open the app from its desktop or Start menu shortcut. App windows support orientation and fullscreen controls. Share files between Windows and the Android guest with a synchronized folder.

Settings include rendering, CPU and memory limits, storage, guest language, and Quick Boot. Built-in diagnostics help you troubleshoot runtime setup, hardware acceleration, networking, and app startup.

## Platform

Windows 10 or Windows 11, x64. Hardware virtualization is recommended. App compatibility varies by Android version and native-library or device requirements.
