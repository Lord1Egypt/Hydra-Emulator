Install Android to Virtual Disk

The emulator window is open. Follow these 6 steps once; thereafter Hydra Emulator boots directly from disk without re-imaging.

  1. Boot Menu: Use ↓ to select Installation - Install Android-x86 to harddisk, then press Enter.
  2. Choose Partition: Select Create/Modify partitions; choose No when asked about GPT.
  3. cfdisk Partitioning: New → Primary → Press Enter for full size → Bootable → Write → type yes → Quit.
  4. Formatting: Select vda1 → choose ext4 when prompted → Yes.
  5. Bootloader & System: Install GRUB choose Yes; Install /system as read-write choose Yes.
  6. Complete: When progress reaches 100%, click "I Have Finished Installation" below (Hydra Emulator will reboot and take over).

If prompted that adb is disconnected: press Ctrl+Alt+F1 in the VM window to open terminal, run setprop service.adb.tcp.port 5555, stop adbd, start adbd, then press Ctrl+Alt+F7 to return to GUI.
